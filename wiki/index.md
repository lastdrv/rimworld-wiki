# RimWorld Modding Wiki (База Знаний)

Добро пожаловать в Wiki по созданию модов для игры **RimWorld** (актуальная версия: **1.6**). Данный ресурс представляет собой связную базу знаний на русском языке, созданную на основе исследований исходного кода и официальной документации разработчиков (`rimworldwiki.com`).

> [!IMPORTANT]
> **Правило терминологии**: Повествовательный текст представлен на русском языке, однако технические термины, имена C#-классов, методов, объектов Unity, теги XML и идентификаторы Defs сохраняются в оригинальном английском виде.

### 2. XML Моддинг (Декларативная конфигурация)
- 📐 **[Основы моддинга RimWorld](основы_моддинга_rimworld.md)**
  *Архитектура модов, структура каталогов `About/`, `Defs/`, `Assemblies/`, `Patches/` и манифест `About.xml`.*
- 📄 **[XML Defs и структура элементов](xml_defs_и_структура_элементов.md)**
  *Базовая структура `<Defs>`, обязательные теги (`defName`, `label`, `description`), наследование XML (`Abstract="True"`, `ParentName`).*
- ⚙️ **[Условная загрузка XML (MayRequire)](условная_загрузка_mayrequire.md)**
  *Условный парсинг элементов для DLC Royalty, Ideology, Biotech, Anomaly и модов с использованием `MayRequire`, `MayRequireAnyOf`, `MayRequireWithAll`.*
- 🔧 **[Патчирование XML (PatchOperations)](патчирование_xml_patchoperations.md)**
  *Модификация чужих Defs с помощью `PatchOperationAdd`, `PatchOperationReplace`, `PatchOperationRemove`, `PatchOperationFindMod` и XPath.*
- 🌐 **[Локализация модов](локализация_модов.md)**
  *Организация переводов в `Languages/`: `DefInjected` для перевода Defs, `Keyed` для UI и `GrammarResolver` для генерации текстов.*

### 3. Практическое создание контента (Tutorials)

### 4. C# Программирование и патчинг (Assemblies)
- 💻 **[Декомпиляция и настройка C#-проекта](декомпиляция_и_настройка_проекта_csharp.md)**
  *Декомпиляция `Assembly-CSharp.dll` через dnSpy/ILSpy, настройка файла проекта `.csproj` и компиляция через `dotnet build`.*
- 🧩 **[Компоненты (ThingComp, GameComponent, WorldComponent)](компоненты_thingcomp_и_gamecomponent.md)**
  *Разработка C#-компонентов объекта (`ThingComp`, `CompProperties`), глобальных менеджеров игры (`GameComponent`) и карты (`MapComponent`).*
- 🔌 **[Расширения Defs (DefModExtension)](расширения_defs_defmodextension.md)**
  *Добавление кастомных C#-полей к ванильным XML Defs без создания подклассов.*
- ⚙️ **[Настройки мода (ModSettings)](настройки_мода_modsettings.md)**
  *Создание пользовательского GUI в меню настроек мода с использованием классов `Mod`, `ModSettings` и `Listing_Standard`.*
- ⚡ **[Модификация кода через Harmony](модификация_кода_harmony.md)**
  *Внедрение и перехват ванильного C#-кода во время выполнения игры с помощью `[HarmonyPatch]`, `Prefix`, `Postfix` и `__instance`.*
- 💾 **[Сохранение данных (ExposeData)](сохранение_данных_exposedata.md)**
  *Сериализация данных мода в файл сохранения (`.rws`) через `IExposable`, `ExposeData()` и методы класса `Scribe`.*
- 👆 **[Контекстное меню и задачи (FloatMenuOptionProvider и Jobs)](контекстное_меню_и_задачи_floatmenu_jobs.md)**
  *Добавление действий по правому клику мыши через `FloatMenuOptionProvider` и написание собственного поведения пешек (`JobDef`, `JobDriver`, `Toil`).*

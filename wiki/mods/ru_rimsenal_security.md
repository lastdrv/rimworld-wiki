# Анализ мода: Русский язык для Rimsenal - Security pack

## 1. Основные сведения
* **Название мода**: Русский язык для Rimsenal - Security pack
* **PackageId**: `RU.rimsenal.security`
* **Steam Workshop ID**: `2590743724`
* **Автор**: Камень
* **Поддерживаемые версии игры**: `1.0`, `1.1`, `1.2`, `1.3`, `1.4`, `1.5`, `1.6`

---

## 2. Цель мода
Мод является неофициальным любительским русификатором для мода **Rimsenal - Security Pack** (`736139206`). Он обеспечивает полный перевод оборонительных построек, турелей, огневых гнезд, снарядов, рецептов и технологий на русский язык.

---

## 3. Зависимости
* **Обязательные моды**: 
  * `rimsenal.security` (Steam ID: `736139206`)
* **Порядок загрузки (`loadAfter`)**:
  * Должен загружаться строго после `rimsenal.security`.

---

## 4. Взаимодействие с ванильными DLC
* Прямого кода взаимодействия нет. Переводит XML Defs мода Rimsenal Security Pack.

---

## 5. Взаимодействие со сторонними библиотеками
* Чистый XML-мод локализации. Код C# отсутствует.

---

## 6. Поддержка и статус русификации
* **Наличие в Steam Workshop**: Да (`294100/2590743724`).
* **Тип мода**: Является готовым сторонним модулем локализации для мода `736139206`.
* **Объем и структура перевода**: 
  * Содержит файлы XML в папке `Languages/Russian/DefInjected/` для категорий `RecipeDef`, `ResearchProjectDef`, `ThingCategoryDef`, `ThingDef` (`Apparel.xml`, `Buildings_Security.xml`, `Item_Security.xml`, `Weapons_Security.xml`).
  * Переводит турели, огневые гнезда, снаряды, мины, оборонительный ранец (`Apparel_DefensePack`) и технологии.
* **Статус**: Перевод распространяется как отдельный мод. По умолчанию при анализе файлы в `russian/` не создавались. В случае явного запроса пользователя материалы данного мода могут быть перенесены в `russian/736139206/` для установки поверх основного мода.

---

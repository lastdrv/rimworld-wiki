# Инструменты для моддинга RimWorld

В данной статье собирается и актуализируется список инструментов, используемых для разработки модов RimWorld. Инструменты разделены на две группы: **GUI-инструменты** для работы разработчика-человека и **CLI-инструменты**, используемые AI-агентом в консольном/автоматическом режиме.

---

## 1. GUI-инструменты (для разработчика)

### IDE и редакторы кода
- **Visual Studio 2022 / JetBrains Rider**
  - Назначение: Полноценная разработка на C#, компиляция assemblies (`.dll`), отладка, инспектирование типов.
  - Особенности: Требуется подключение ссылок на `Assembly-CSharp.dll` и `UnityEngine.CoreModule.dll` из папки RimWorld.
- **Visual Studio Code**
  - Назначение: Легковесный редактор для работы с XML-файлами Defs, Patches и C#-файлами.
  - Рекомендуемые расширения: *XML Tools*, *C# Dev Kit*, *RimWorld XML Language Support*.

### Декомпиляторы и исследователь исходного кода RimWorld
- **dnSpy / dnSpyEx**
  - Назначение: Декомпиляция `Assembly-CSharp.dll` в исходный C#-код, просмотр IL-кода, отладка модов прямо в процессе работы игры.
- **ILSpy**
  - Назначение: Мощный open-source декомпилятор C#. Удобен для поиска использования методов и анализа внутренней логики ванильной игры.
- **JetBrains dotPeek**
  - Назначение: Бесплатный декомпилятор .NET от JetBrains с высокой точностью восстановления C#-кода.

### Работа с графикой и ресурсами (Textures & Sprites)
- **Paint.NET / GIMP / Adobe Photoshop**
  - Назначение: Создание и редактирование PNG-текстур для объектов (`ThingDef`), UI, одежды, оружия.
  - Требования к формату: PNG с прозрачностью, стандарты размера обычно 64x64, 128x128, 256x256, 512x512 пикселей.
- **Aseprite**
  - Назначение: Пиксель-арт и анимации (если используются текстуры в стиле пиксель-арт).
- **AssetRipper / Unity Asset Studio**
  - Назначение: Извлечение ресурсоемких Unity-ассетов, спрайтов, звуков и шейдеров из скомпилированных бандлов RimWorld (`RimWorldWin64_Data/`).

### Управление модами и окружением
- **RimPy Mod Manager**
  - Назначение: Управление порядком загрузки модов, автоматическая сортировка, проверка конфликтов, сжатие текстур в формат `.dds`.

## 2. CLI-инструменты (для AI-агента в автономном режиме)

### Сборка и компиляция C#
- **`dotnet` CLI** (`dotnet build`, `dotnet new`)
  - Назначение: Создание C#-проектов `.csproj`, автоматическая сборка `.dll` сборок для RimWorld модов без использования тяжелого GUI.
  - Пример использования: `dotnet build -c Release`
- **`csc` (C# Compiler / Roslyn)**
  - Назначение: Прямая компиляция файлов исходного кода `.cs` в `.dll` при отсутствии `.csproj`.

### Декомпиляция и CLI-анализ Assemblies
- **`ilspycmd` (ILSpy CLI)**
  - Назначение: Консольная декомпиляция `Assembly-CSharp.dll` или модов в файлы `.cs` для автоматического поиска и анализа методов агентом.
  - Установка: `dotnet tool install -g ilspycmd`
- **`ildasm` / `monodis`**
  - Назначение: Дизассемблирование C# сборок в IL-код.

### Обработка и генерация изображений / текстур
- **`ImageMagick` (`magick` / `convert`)**
  - Назначение: Консольное изменение размеров текстур, конвертация форматов, генерация альфа-каналов, обрезка и сжатие PNG.
- **PowerShell / Python Scripts (`Pillow`)**
  - Назначение: Автоматизированный пакетный анализ размеров текстур, проверка корректности структуры каталогов `Textures/`.

### Поиск, навигация и сопоставление кодов
- **`git`**
  - Назначение: Контроль версий, отслеживание изменений в коде мода и синхронизация с репозиторием.
- **PowerShell CLI / `Select-String` / `grep`**
  - Назначение: Быстрый полнотекстовый поиск по тысячам ванильных XML Defs (`C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Data\Core\Defs`) и модам из Workshop.

## 3. Таблица быстрого выбора инструмента

| Задача | GUI инструмент (пользователь) | CLI инструмент (AI агент) |
|---|---|---|
| Компиляция C# кода | Visual Studio / Rider | `dotnet build` |
| Поиск по XML Defs | VS Code | `Select-String` / `grep` |
| Чтение кода игры | dnSpy / ILSpy | `ilspycmd` |
| Редактирование графики | Photoshop / Paint.NET | ImageMagick / Python Pillow |
| Контроль версий | GitHub Desktop / GitKraken | `git` CLI |

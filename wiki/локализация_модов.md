# Локализация модов RimWorld

Система локализации RimWorld позволяет переводить названия, описания и интерфейсные строки мода на различные языки без редактирования исходных файлов `Defs`. Все переводы хранятся в папке мода `Languages/`.

---

## 1. Структура папки `Languages/`

```text
my_mod/
└── Languages/
    └── Russian/
        ├── DefInjected/
        │   ├── ThingDef/
        │   │   ├── Weapons_MyMod.xml
        │   │   └── Buildings_MyMod.xml
        │   └── RecipeDef/
        ├── Keyed/
        │   └── Interface_MyMod.xml
        └── Strings/
            └── Names/
```

---

## 2. Перевод Defs (`DefInjected`)

В папке `DefInjected/<DefType>/` создаются XML-файлы с переводами полей конкретных `Def`.

### Формат обращения к полям
Синтаксис узлов перевода: `<defName.field>Перевод</defName.field>`

Пример файла `Languages/Russian/DefInjected/ThingDef/Weapons.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<LanguageData>

  <!-- Перевод полей label и description -->
  <MyCustomRifle.label>опытная винтовка</MyCustomRifle.label>
  <MyCustomRifle.description>Мощная винтовка, разработанная на верстаке.</MyCustomRifle.description>

  <!-- Перевод элементов списков (например, подтипов атаки) -->
  <MyCustomRifle.tools.barrel.label>ствол</MyCustomRifle.tools.barrel.label>
  <MyCustomRifle.tools.stock.label>приклад</MyCustomRifle.tools.stock.label>

</LanguageData>
```

## 3. Перевод интерфейсных строк (`Keyed`)

Файлы в `Languages/Russian/Keyed/` содержат переводы надписей для UI, меню настроек мода и сообщений C#-кода.

Пример файла `Languages/Russian/Keyed/UI_MyMod.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<LanguageData>
  <MyMod_SettingTitle>Настройки производительности мода</MyMod_SettingTitle>
  <MyMod_EnableFeature>Включить дополнительный модуль</MyMod_EnableFeature>
  <MyMod_PawnMessage>Пешка {PAWN_labelShort} успешно активировала устройство.</MyMod_PawnMessage>
</LanguageData>
```

### Использование в C# коде
В C#-коде обращение к Keyed-строкам выполняется через метод расширения `.Translate()`:
```csharp
string title = "MyMod_SettingTitle".Translate();
string message = "MyMod_PawnMessage".Translate(pawn.Named("PAWN"));
```

---

## 4. Генератор грамматики и имена (`GrammarResolver`)

В RimWorld для динамической генерации текстов (названия фракций, историй пешек, ритуалов) используется класс `GrammarResolver`. Переводы правил генерации помещаются в `Languages/Russian/Grammar/` или `DefInjected/RulePackDef/`.

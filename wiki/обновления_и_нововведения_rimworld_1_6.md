# Обновления и нововведения RimWorld 1.6

В данной статье собраны ключевые изменения API, новые типы Defs и нововведения версия игры **RimWorld 1.6** (сборка `1.6.4871 rev590`).

---

## 1. Платформенные и системные обновления

- **Версия движка Unity**: Обновлено до Unity **2022.3.35f1**.
- **C# и .NET Runtime**: Поддержка синтаксических возможностей C# 10 и .NET Framework 4.8 / .NET Standard 2.1.
- **Поддержка DLC Odyssey**: Добавлены новые структуры данных для космических/планетарных систем, орбитальных механик и расширенного генератора биомов.

---

## 2. Изменения в XML Defs [1.6+]

- **Расширенные условные операторы загрузки XML**:
  - Введены `MayRequireAnyOf` и `MayRequireWithAll` для создания гибких логических связей без сложной вложенности `PatchOperationFindMod`.
- **Новые свойства `PlantDef`**:
  - Добавлена поддержка динамической ветроустойчивости и оптимизированного рендеринга травы и деревьев на больших картах.
- **Новые теги в `ThingDef`**:
  - Дополнительные параметры фильтрации для графических ресурсов и спрайтов с высоким разрешением (`Graphic_Multi` и подтипы).

---

## 3. Изменения в C# API и оптимизация

- **Система контекстных меню (`FloatMenuOptionProvider`)**:
  - Окончательный переход от старых громоздких патчей `FloatMenuMakerMap` к модульным `FloatMenuOptionProvider` классам, снижающим вероятность конфликтов между модами.
- **Оптимизация производительности тиков (`TickManager`)**:
  - Улучшен параллелизм обработчиков тиков пешек и объектов на карте.
  - Рекомендуется использовать метод `IsHashIntervalTick(N)` вместо проверок `Find.TickManager.TicksGame % N == 0`.

---

## 4. Рекомендации по миграции модов с 1.5 на 1.6

1. Обновите файл манифеста `About/About.xml`:
   ```xml
   <supportedVersions>
     <li>1.5</li>
     <li>1.6</li>
   </supportedVersions>
   ```
2. Перекомпилируйте C# `.dll` сборки с обновленными ссылками на `Assembly-CSharp.dll` и `UnityEngine.CoreModule.dll` из директории RimWorld 1.6.
3. Проверьте логи игры (`C:\Users\lastdrv\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Player.log`) на предмет устаревших (`obsolete`) методов и вызовов API.

## Часть 1. Первый мод и настройка манифеста (`About.xml`)

Создание модов для RimWorld не требует сложной предварительной подготовки или специальных среды разработки. Множество задач можно решить с помощью базовых текстовых редакторов.

### 🛠️ Требования
- Умение создавать папки в ОС.
- Любой текстовый редактор (Notepad, Notepad++, Visual Studio Code).

### 🚀 Пошаговый процесс
1. Перейдите в папку модов игры:
   ```text
   C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods\
   ```
2. Создайте новую папку для вашего мода, например: `HelloWorld`.
3. Внутри `HelloWorld` создайте папку `About` (с соблюдением регистра).
4. В папке `About` разверните два файла:
   - `Preview.png` — изображение-превью в меню игры (формат PNG).
   - `About.xml` — метаданные мода.

5. Заполните `About/About.xml`:
```xml
<?xml version="1.0" encoding="utf-8"?>
<ModMetaData>
    <name>Hello, Modding World!</name> <!-- Имя мода в списке -->
    <author>John Doe</author>
    <supportedVersions>
        <li>1.1</li>
        <li>1.2</li>
        <li>1.3</li>
        <li>1.4</li>
        <li>1.5</li>
        <li>1.6</li>
    </supportedVersions>
    <packageId>johndoe.helloworld</packageId> <!-- Уникальный ID мода (a-z, точки, без пробелов) -->
    <description>
Поздравляем! Вы создали свой первый мод для RimWorld.
    </description>
</ModMetaData>
```

6. Запустите RimWorld, откройте меню **Моды** и убедитесь, что ваш мод отображается в списке.

## Часть 2. Изменение характеристик существующих объектов (XML-патчи)

Значительная часть моддинга заключается в модификации существующих элементов игры без написания нового C#-кода.

### 🚀 Пример задачи: Модификация Маффало (Muffalo)
Мы хотим:
1. Увеличить выработку шерсти со 120 до 240 единиц.
2. Добавить Маффало способность нести куриные яйца.

### 🛠️ Пошаговый процесс
1. **Поиск оригинального Def**: В папке `Data/Core/Defs/` найдем определение `Muffalo` в файле `Races_Animal_Warm.xml`.
2. **Создание структуры патча**: В корне мода создадим папку `Patches` и файл `muffalo.xml`.
3. **Написание патча**:

```xml
<?xml version="1.0" encoding="utf-8"?>
<Patch>

    <!-- 1. Замена выработки шерсти (PatchOperationReplace) -->
    <Operation Class="PatchOperationReplace">
        <xpath>/Defs/ThingDef[defName="Muffalo"]/comps/li/woolAmount</xpath>
        <value>
            <woolAmount>240</woolAmount>
        </value>
    </Operation>

    <!-- 2. Добавление компонента откладывания яиц (PatchOperationAdd) -->
    <Operation Class="PatchOperationAdd">
        <xpath>/Defs/ThingDef[defName="Muffalo"]/comps</xpath>
        <value>
            <li Class="CompProperties_EggLayer">
                <eggUnfertilizedDef>EggChickenUnfertilized</eggUnfertilizedDef>
                <eggFertilizedDef>EggChickenFertilized</eggFertilizedDef>
                <eggFertilizationCountMax>1</eggFertilizationCountMax>
                <eggLayIntervalDays>1</eggLayIntervalDays>
                <eggCountRange>1</eggCountRange>
            </li>
        </value>
    </Operation>

</Patch>
```

4. Запустите игру с включенным **Режимом разработчика** (Dev Mode) и проверьте Маффало в игре.

## Часть 3. Создание новых предметов, рецептов и графики

В этой части мы создадим абсолютно новый предмет еды — **Кукурузный хлеб (Cornbread)**, привяжем к нему рецепт приготовления на костре и добавим текстуры.

### 🛠️ Пошаговый процесс
1. В корне мода создайте папку `Defs` и файл `Cornbread.xml`:

```xml
<?xml version="1.0" encoding="utf-8" ?>
<Defs>

    <!-- Рецепт приготовления -->
    <RecipeDef ParentName="CookMealBase">
        <defName>CookCornbread</defName>
        <label>испечь кукурузный хлеб</label>
        <description>Приготовить сытный кукурузный хлеб из свежей кукурузы.</description>
        <jobString>Печет кукурузный хлеб.</jobString>
        <workSpeedStat>CookSpeed</workSpeedStat>
        <requiredGiverWorkType>Cooking</requiredGiverWorkType>
        <effectWorking>Cook</effectWorking>
        <soundWorking>Recipe_CookMeal</soundWorking>
        <allowMixingIngredients>false</allowMixingIngredients>
        <ingredientValueGetterClass>IngredientValueGetter_Nutrition</ingredientValueGetterClass>
        <ingredients>
            <li>
                <filter>
                    <thingDefs>
                        <li>RawCorn</li>
                    </thingDefs>
                </filter>
                <count>0.5</count>
            </li>
        </ingredients>
        <products>
            <Cornbread>1</Cornbread>
        </products>
        <workSkill>Cooking</workSkill>
    </RecipeDef>

    <!-- Предмет еды -->
    <ThingDef ParentName="MealCooked">
        <defName>Cornbread</defName>
        <label>кукурузный хлеб</label>
        <description>Вкусный и питательный хлеб, выпеченный из кукурузы.</description>
        <graphicData>
            <texPath>Things/Cornbread</texPath> <!-- Путь внутри Textures/ -->
            <graphicClass>Graphic_StackCount</graphicClass>
        </graphicData>
        <statBases>
            <MarketValue>15</MarketValue>
            <WorkToMake>300</WorkToMake>
            <Nutrition>0.9</Nutrition>
        </statBases>
        <ingestible>
            <preferability>MealSimple</preferability>
            <ingestEffect>EatVegetarian</ingestEffect>
            <ingestSound>Meal_Eat</ingestSound>
        </ingestible>
    </ThingDef>

</Defs>
```

2. **Графика**: Поместите PNG-картинки с прозрачным фоном в папку `Textures/Things/Cornbread/`:
   - `Cornbread_a.png` (один предмет)
   - `Cornbread_b.png` (стопка предметов)

3. **Патч рабочего места**: В `Patches/CampfirePatch.xml` добавим рецепт костру (`Campfire`):
```xml
<?xml version="1.0" encoding="utf-8"?>
<Patch>
    <Operation Class="PatchOperationAdd">
        <xpath>/Defs/ThingDef[defName="Campfire"]/recipes</xpath>
        <value>
            <li>CookCornbread</li>
        </value>
    </Operation>
</Patch>
```

## Часть 4. Совместимость мода с разными версиями RimWorld

Движок RimWorld сканирует версионные папки в моде (`1.0`, `1.1`, `1.3`, `1.5`, `1.6` или `Common`).

### 🧠 Принцип работы
* Если у вас есть несколько версионных папок, игра выбирает наивысшую подходящую папку для текущей версии.
* Файлы из версионной папки переопределяют аналогичные файлы из корня.
* Общую графику и звуки следует хранить в корневых папках или в `Common/`.

### 📁 Пример структуры мультиверсионного мода
```text
ExampleVersions/
├── About/About.xml
├── Textures/Things/Cornbread/
├── 1.0/Defs/Meals/Cornbread.xml
├── 1.3/Defs/Meals/Cornbread.xml
└── 1.6/Defs/Meals/Cornbread.xml
```

## Часть 5. Совместимость с другими модами

Если ваш мод расширяет контент другого стороннего мода или DLC, но должен работать и при их отсутствии, используйте условную операцию **`PatchOperationFindMod`**.

```xml
<?xml version="1.0" encoding="utf-8"?>
<Patch>
    <Operation Class="PatchOperationFindMod">
        <mods>
            <li>Polyamory Beds (Vanilla Edition)</li> <!-- Название или packageId -->
        </mods>
        <match Class="PatchOperationSequence">
            <success>Always</success>
            <operations>
                <li Class="PatchOperationAdd">
                    <xpath>Defs/ThingDef[defName="BedrollTriple"]/statBases</xpath>
                    <value>
                        <WorkToMake>1600</WorkToMake>
                    </value>
                </li>
            </operations>
        </match>
    </Operation>
</Patch>
```

*Для условной загрузки узлов внутри Defs также используется атрибут `MayRequire="Package.Id"`.*

## Часть 6. Теоретическое введение в C# DLL-моды

Если идея требует принципиально новой механики (новые AI-поведения поселенцев `JobDriver`, кастомный UI, изменение расчетов температуры или глобальных условий), XML недостаточно — необходим C#-код.

### 🧩 C# и компиляция
* **XML-файлы** интерпретируются игрой прямо на лету.
* **C#-код** компилируется с помощью компилятора (`csc` или `dotnet build`) в откомпилированную динамическую библиотеку (`library.dll`).
* При старте RimWorld автоматически загружает `.dll` файлы из папок `Assemblies/` каждого активного мода.

## Часть 7. Практическое создание первого C# DLL-мода

Создадим C# DLL-мод уровня «Hello World», который при запуске игры выведет отладочное сообщение в консоль разработчика.

### 🚀 Пошаговый процесс

1. **Структура папок**:
   ```text
   HelloWorldDLL/
   ├── About/About.xml
   ├── Assemblies/      <-- Сюда поместим готовый library.dll
   └── Source/          <-- Сюда помещается HelloWorld.cs
   ```

2. **Создание C#-файла** (`Source/HelloWorld.cs`):
```csharp
using RimWorld;
using Verse;

namespace HelloWorld
{
    [StaticConstructorOnStartup]
    public static class HelloWorld
    {
        static HelloWorld()
        {
            Log.Message("Hello World!");
        }
    }
}
```

3. **Компиляция через консоль**:
   В папке мода выполните команду компиляции (`csc`):
   ```cmd
   csc -t:library -out:Assemblies/library.dll -r:"../../RimWorldWin64_Data/Managed/Assembly-CSharp.dll" Source/*.cs
   ```

4. **Автоматизация сборки** (`compile.bat`):
   ```cmd
   @echo off
   csc -t:library -out:Assemblies/library.dll -r:"../../RimWorldWin64_Data/Managed/Assembly-CSharp.dll" Source/*.cs
   echo Compilation complete!
   pause
   ```

5. **Проверка в игре**: Запустите RimWorld с включенным режимом разработчика, активируйте мод и откройте консоль логов — вы увидите запись `"Hello World!"`.

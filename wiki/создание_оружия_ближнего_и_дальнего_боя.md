# Создание оружия ближнего и дальнего боя

Оружие в RimWorld описывается с помощью `ThingDef` с категорией `Item`. Для оружия дальнего боя дополнительно создается `ThingDef` снаряда (`Projectile`).

---

## 1. Оружие ближнего боя (Melee Weapon)

Файл `Defs/ThingDefs_Misc/Weapons_Melee.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<Defs>

  <ThingDef ParentName="BaseMeleeWeaponMakeable">
    <defName>MyMod_TitaniumSword</defName>
    <label>titanium sword</label>
    <description>A sharp high-tech sword made of titanium.</description>
    <graphicData>
      <texPath>Things/Item/Equipment/WeaponMelee/TitaniumSword</texPath>
      <graphicClass>Graphic_Single</graphicClass>
    </graphicData>
    <techLevel>Industrial</techLevel>
    <costList>
      <Steel>50</Steel>
      <Plasteel>30</Plasteel>
    </costList>
    <statBases>
      <WorkToMake>12000</WorkToMake>
      <Mass>1.8</Mass>
      <MarketValue>450</MarketValue>
    </statBases>
    <equippedAngleOffset>-45</equippedAngleOffset>
    <tools>
      <li>
        <label>point</label>
        <capacities>
          <li>Stab</li>
        </capacities>
        <power>22</power>
        <cooldownTime>1.8</cooldownTime>
      </li>
      <li>
        <label>edge</label>
        <capacities>
          <li>Cut</li>
        </capacities>
        <power>18</power>
        <cooldownTime>1.5</cooldownTime>
      </li>
    </tools>
    <recipeMaker>
      <recipeUsers>
        <li>FueledSmithy</li>
        <li>ElectricSmithy</li>
      </recipeUsers>
      <researchPrerequisite>LongBlades</researchPrerequisite>
    </recipeMaker>
  </ThingDef>

</Defs>
```

## 2. Оружие дальнего боя (Ranged Weapon)

Оружие дальнего боя требует два `ThingDef`: один для самого оружия и один для летящего снаряда (`Projectile`).

### Шаг 1: Описание снаряда (`Bullet`)
```xml
<ThingDef ParentName="BaseBullet">
  <defName>Bullet_MyPlasmaRifle</defName>
  <label>plasma bolt</label>
  <graphicData>
    <texPath>Things/Projectile/PlasmaBolt</texPath>
    <graphicClass>Graphic_Single</graphicClass>
  </graphicData>
  <projectile>
    <damageDef>Bullet</damageDef>
    <damageAmountBase>18</damageAmountBase>
    <stoppingPower>1.2</stoppingPower>
    <speed>70</speed>
  </projectile>
</ThingDef>
```

### Шаг 2: Описание оружия (`Gun`)
```xml
<ThingDef ParentName="BaseHumanMakeableGun">
  <defName>Gun_MyPlasmaRifle</defName>
  <label>plasma rifle</label>
  <description>An advanced rifle firing superheated plasma bolts.</description>
  <graphicData>
    <texPath>Things/Item/Equipment/WeaponRanged/PlasmaRifle</texPath>
    <graphicClass>Graphic_Single</graphicClass>
  </graphicData>
  <soundInteract>Interact_Rifle</soundInteract>
  <statBases>
    <WorkToMake>30000</WorkToMake>
    <Mass>3.2</Mass>
    <AccuracyTouch>0.75</AccuracyTouch>
    <AccuracyShort>0.85</AccuracyShort>
    <AccuracyMedium>0.70</AccuracyMedium>
    <AccuracyLong>0.55</AccuracyLong>
    <RangedWeapon_Cooldown>1.4</RangedWeapon_Cooldown>
  </statBases>
  <verbs>
    <li>
      <verbClass>Verb_Shoot</verbClass>
      <hasStandardTargeting>true</hasStandardTargeting>
      <defaultProjectile>Bullet_MyPlasmaRifle</defaultProjectile>
      <warmupTime>1.0</warmupTime>
      <range>28.9</range>
      <burstShotCount>3</burstShotCount>
      <ticksBetweenBurstShots>8</ticksBetweenBurstShots>
      <soundCast>Shot_PlasmaRifle</soundCast>
      <soundCastTail>GunTail_Medium</soundCastTail>
      <muzzleFlashScale>9</muzzleFlashScale>
    </li>
  </verbs>
  <tools>
    <li>
      <label>stock</label>
      <capacities>
        <li>Blunt</li>
      </capacities>
      <power>9</power>
      <cooldownTime>2.0</cooldownTime>
    </li>
    <li>
      <label>barrel</label>
      <capacities>
        <li>Blunt</li>
        <li>Poke</li>
      </capacities>
      <power>9</power>
      <cooldownTime>2.0</cooldownTime>
    </li>
  </tools>
</ThingDef>
```

---

## 3. Требования к текстурам оружия
- Файлы помещаются в `Textures/Things/Item/Equipment/WeaponMelee/` или `WeaponRanged/`.
- Формат: PNG с прозрачностью.
- Стандартная ориентация ствола оружия: смотрит вправо вверх или вправо.
